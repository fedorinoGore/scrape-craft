## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## ScrapeCraft

This is a great MVP for demonstrating my full-stack developer skills.
The app uses Next.js, Tailwind CSS and the shadcn/ui technology stack.
Clerk for easy authentification. In future versions it will be replaced with a dedicated microservice.
Stripe for billing.
The UI is built around a WYSIWYG dragabble interface that allows the user to quickly scaffold data scraping flows and get the results in JSON format.
